### 核心知识点总结

- **默认参数**：定义函数时给参数默认值（如 `greeting="你好"`），调用时可省略。
- **处理空列表**：在列表统计函数开头加 `if not numbers: return None, None, None`，防止除以零报错。
- **提取缺失字段**：使用字典的 `item.get(key, default_value)` 代替 `item[key]`，防止抛出 `KeyError`。

### 5道小练习边界情况分析

1. **列表平方**：空列表 `[]` 返回 `[]`。
2. **字符计数**：空字符串 `""` 返回 `{}`。
3. **反转列表**：单元素列表 `[1]` 返回 `[1]`。
4. **偶数判断**：0 返回 `True`，负数同样适用。
5. **合并字典**：空字典返回 `{}`，键冲突时后者覆盖前者。
